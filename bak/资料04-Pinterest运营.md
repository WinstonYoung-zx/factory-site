## 1. 为什么 Pinterest 适合这个品类 + 目标受众

### 1.1 平台与品类的匹配逻辑（中文说明）

Pinterest 不是即时社交，而是**"灵感收藏 + 采购前搜索"引擎**。用户在这里做 mood board、找方案、存参考，一个 Pin 被 save 后可在数月内持续被 search / 相关推荐带出——长尾寿命远大于一条 LinkedIn 帖或一封 EDM。

这个品类天然适配：
- **强视觉、弱文字**：候车亭、灯箱、导视、LED 结构，靠实景图与设计图说话，正是 Pinterest 的核心载体。
- **决策链上有"找参考"环节**：建筑师、景观设计师、广告公司、市政 planner 在方案阶段就会大量搜 "bus shelter design"、"wayfinding signage ideas"、"airport signage system"，并把好图存进画板给客户/同事看。
- **B2B 也能吃到长尾**：访客点 Pin 回官网产品页时，已进入"看具体产品"的高意图状态，比泛流量更接近询价。

### 1.2 四类目标受众

| 受众 | 在 Pinterest 上找什么 | 我们对应的内容 |
|---|---|---|
| 建筑师 / 设计院 | 城市家具、候车亭、公共空间导视的实景与设计参考 | Bus Shelter / Urban Furniture / Wayfinding 画板 |
| 景观设计师 | 户外广告与公共空间的融合、材质与安装方式 | Outdoor Advertising / Project Case Studies 画板 |
| 广告公司 / 媒体代理 | 灯箱形态、LED/LCD 显示结构、创意装置 | Light Boxes / LED & LCD Structures 画板 |
| 市政 planner / 采购方 | 合规性、耐久、可落地的产品与供应商 | Compliance & Standards / Metal Fabrication 画板 |

### 1.3 与官网资产联动的逻辑（中文说明）

```
Pinterest（发现 / 灵感 / 收藏）
   │  Pin 上放"场景图 + 关键词 + 明确 CTA"
   ▼
官网产品页 / 博客（承接 / 说服 / 建立信任）
   │  UTM 标记来源；页面主题与 Pin 强相关
   ▼
产品页看规格 + 案例页看实景 + 博客看选型/合规
   │  页面内 CTA：Request a Quote / Download spec / Contact
   ▼
询盘（sales@zhanxinglobal.com）
```

- **产品实景 Pin → 对应产品页**：看到什么就落到什么，避免"图是候车亭、链接到首页"。
- **技术/选型/合规 Pin → 对应博客**：用深度内容承接专业搜索流量，博客内再链产品页。
- **工厂/生产 Pin → 产品页或 about**：传递"制造能力可信度"，海外买家下单前必看。
- 每个 Pin 都是"官网内容的视觉入口"，Pinterest 负责被找到，官网负责被相信。

### 2.3 关于外链权重的预期管理（务必让团队知道）

> **Pinterest 外链默认 `nofollow`。** 它的价值在于**视觉曝光 + 品牌搜索 + 长尾点击**，**不是**给官网传递 SEO 权重 / PageRank。
>
> 因此：
> - 不要把 Pinterest 当作"外链建设"或"权重传递"渠道来考核；追踪表中它属于"视觉分发"，与 nofollow 一致。
> - KPI 应看：impressions（曝光）、outbound clicks（出站点击）、saves（收藏）、品牌搜索量变化、GA4 中 Pinterest 引荐会话数——而不是"外链权重分"。
> - 真正的 SEO 收益是间接的：更多品牌搜索 + 产品页被真实访客访问 + 内容被二次引用。

## 6. 作图规范

### 6.1 尺寸与比例
- **主推 2:3 竖版，1000 × 1500 px**（Pinterest 信息流最佳，占屏最大）。
- 备选 1:1（1000 × 1000）用于 Idea Pin 封面；**避免横版**（横向在手机端显示很小、易被裁切）。
- 单图 < 10 MB，格式 JPG/PNG；文件命名英文小写连字符，便于复用。
- 同一选题可出 2–5 张图的 **Idea Pin**：图 1 场景大图（封面）、图 2 细节/结构、图 3 工厂或安装过程、图 4 规格/选型要点、图 5 CTA（官网 + 品牌）。

### 6.2 文字叠加建议
- 在图上加**简短大字标题**，4–8 个英文词，例如 "BUILT FOR REAL CITIES" / "CUSTOM LIGHT BOX" / "MADE TO DRAWING"。
- 文字放在画面**上 1/3 或下 1/4**，避开 Pinterest 界面覆盖区域；对比度足够（深底白字或浅底深蓝字）。
- **不要**把整段描述压在图上；描述写在 Pin 文本里。
- 图片本身即内容，叠加文字是"锦上添花"，不要遮挡产品主体。

### 6.3 品牌色 / Logo
- 主色取品牌蓝（从 `uploads/logo-zhanxin-blue.png` 取色），建议深蓝作文字/色块，白或浅灰作背景；**不要自拟 HEX**，以 logo 实物取色为准。
- Logo 放置：右上角或底部居中，宽度不超过画面宽 20%，留白充足。
- 每批图风格统一（同一色系 + 同一标题样式），让主页画板看起来像专业品牌而非杂图集合。

### 6.4 Alt Text 写法（无障碍 + SEO）

每张图填 alt text，格式：`主体 + 场景/属性 + 品牌`，自然含 1 个关键词，不堆砌。

**英文示例**
```
Modern powder-coated steel bus shelter in a city street setting by ZHANXIN GLOBAL
Custom frameless tension fabric light box, front view for retail advertising
Welding a custom steel light box frame in the ZHANXIN GLOBAL Shanghai workshop
Wayfinding signage system installed at a metro station exit
```
**公式**
```
[产品/主体] + [材质/颜色/视角] + [场景] + by ZHANXIN GLOBAL
```
> Alt text 既服务视障用户（无障碍），也被 Pinterest 用于理解图片内容（SEO），必填。

## 7. 发布与维护 SOP

### 7.1 发布节奏
- **起步期（第 1 个月）**：每周 10–15 个 Pin，分散在 3–5 个画板；先把第 5 节 20 个选题发完。
- **稳定期**：每周 15–25 个 Pin；新品图/新博客上线即补 Pin。
- 同图不同裁切/文字可复用为 2–3 个变体，但**不要同一张图同一天连发**，分散到不同周。
- 每个 Pin 落到**不同**画板或不同角度，避免单个画板短期灌满。

### 7.2 最佳发布时间
- 按**目标受众时区**（先按美东 ET 试）： workday 晚间 20:00–23:00、周末上午 09:00–11:00 通常互动较高。
- **以自己 Analytics 为准**：跑满 4 周后按 impressions/clicks 高峰调整；不同市场时区不同，必要时分账号/分时段测试。
- 用 scheduler 定时发布，保证节奏稳定。

### 7.3 发布工具：Tailwind 或原生 scheduler
- **原生 scheduler**（Pinterest 内置）：免费、账号安全、最稳，适合起步；可提前排 2–3 周。
- **Tailwind**（第三方，Pinterest 官方合作）：批量上传、智能排期、循环 repin、看板视图，适合稳定期增长；注意账号授权安全与费用。
- 二者选一即可，不要同时操作同一账号导致重复排期。

### 7.4 repin 养号
- 初期"自有 Pin : 他人相关 Pin"约 **1 : 2–3**：多 repin 建筑师、设计师、城市家具、导视灵感类的高质量图到自己的灵感画板（可建 Secrets 参考板）。
- 只 repin **非直接竞品**、与品类相关的灵感内容；带来源 attribution，遵守版权。
- 每天 repin 10–20 个，持续养号信号；自己的 Pin 每周稳定新增。
- repin 也能触发"你可能也喜欢"的关联曝光，间接带出自己的 Pin。

### 7.5 Pinterest Analytics 看什么
关注四个核心指标（Business 账号 → Analytics）：
| 指标 | 含义 | 判断 |
|---|---|---|
| Impressions | Pin 被展示次数 | 看趋势与哪些主题被推荐 |
| Outbound clicks | 点回官网次数 | 直接反映引流效果，核心 KPI |
| Saves | 被收藏次数 | 高 save = 内容有长尾潜力 |
| Pin click rate | clicks / impressions | 衡量标题图+文案吸引力 |

操作：
- 按 **Pin** 看：找出 high-save / high-click 的主题与画板。
- 按 **Board** 看：哪些画板产出高，就加大投入。
- 每周记录到追踪表（资料03 第 18 行），与 GA4 引荐数据对照。

### 7.6 把高 save 的 Pin 反哺成博客选题
- 若某个技术/合规类 Pin（如 IP rating、LED vs LCD）save 持续走高 → 说明需求旺，写成/扩写博客，并把博客拆成 3–5 个新 Pin 回引。
- 若某类产品实景 save 高 → 补产品页细节图、规格表、案例，做成 Idea Pin（多图）。
- 形成闭环：`Pin 数据 → 选题 → 博客/产品页 → 新 Pin → 更多 save`。

## 8. 与站内资产的联动

### 8.1 UTM 标记（每个 Pin 必带）

**标准串**
```
utm_source=pinterest&utm_medium=social&utm_campaign=<主题>&utm_content=<pin标识>
```
- `utm_source=pinterest`（固定）
- `utm_medium=social`（固定，与资料03追踪表口径一致）
- `utm_campaign`：按画板/选题命名，如 `bus_shelter`、`light_box`、`compliance_ip`
- `utm_content`：可选，区分具体 Pin，如 `pin01_busshelter`

**完整示例**
```
https://www.zhanxinglobal.com/product/bus-shelter?utm_source=pinterest&utm_medium=social&utm_campaign=bus_shelter&utm_content=pin01_real_scene
```
> 注意：Pinterest 自身也会附加点击参数；保留我们的 UTM 即可，不影响 GA4 识别 source/medium。

### 8.2 落地页强相关
- 图是候车亭 → 落 `/product/bus-shelter`，不落首页；图是 LED 屏 → 落对应显示产品页。
- 技术/合规 Pin → 落对应博客，博客内再链产品页（二次转化路径）。
- 落地页必须**存在且能打开**（无 .html 后缀，见第 0 节），发布前用浏览器逐个验证，杜绝 404。

### 8.3 在 GA4 看 Pinterest 引荐
- 路径：`Acquisition（获客） → Traffic acquisition（流量获取）`，按 `Session source / medium` 查看。
- 预期看到 `pinterest / social`（由 UTM 保证）；若看到 `pinterest.com / referral`，说明部分点击未带 UTM，需补。
- 在 `Engagement → Landing page` 看 Pinterest 流量具体落到哪些产品页/博客，验证"落地页强相关"是否执行到位。
- 每周把 GA4 的 Pinterest 会话数、转化率与 Pinterest Analytics 的 outbound clicks 对照，评估真实引流质量。

## 9. 常见错误警示（6 条）

1. **图片用横向 / 小图**：横向在手机端显示小且被裁；坚持 2:3 竖版 1000×1500，主图清晰。
2. **Description 堆关键词**：把 20 个词塞满描述会显得 spam、降低可信度；前 150 字自然含 1–2 个核心词即可，标签适度。
3. **落地页 404 / 落到首页**：产品图却链到首页或错误路径（注意 URL 无 .html）；发布前逐个点开验证，图与页强相关。
4. **只发产品白底图、无场景**：Pinterest 用户要"灵感"不是"目录"；多发真实安装/使用场景图，白底图最多作补充。
5. **不 claim 官网**：未验证则主页无 verified merchant 标识、Pin 不显示来源域名、无 Rich Pins 与 Analytics；开号第一件事就是 claim。
6. **预期直接 SEO 权重**：外链默认 nofollow，不传权重；把它当视觉曝光/品牌搜索/长尾点击渠道，用 impressions/clicks/saves 与 GA4 引荐考核，而不是"外链权重"。
