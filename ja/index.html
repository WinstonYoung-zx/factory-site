品質とコンプライアンス

  • 生産安全許可証（中国）— 金属加工メーカーとしての許可を取得
  • ISO 9001 / 14001 / 45001 に基づく品質マネジメントシステムを構築済み。再認証手続きを進めています
  • 入荷時検査、工程中検査、出荷前の 100% 最終検査を実施
  • 製鉄所発行の EN 10204 3.1 材料証明書を提供可能
  • 溶接施工要領書（WPS/PQR）および溶接士資格記録を提供可能
  • 塗膜厚さ・塩水噴霧試験の第三者試験機関による試験報告書をプロジェクト要件に応じて提供可能
  • 屋外用筐体の IP 保護等級試験報告書（IEC 60529）をプロジェクト単位で提供可能
  • 購入者のご要望に応じて第三者による出荷前検査を手配可能
  • 対象市場の認証（EN 1090 / CE / UL / SASO / ECAS / G-Mark）はプロジェクト単位で手配可能。試験は購入者指定の試験機関が実施します
